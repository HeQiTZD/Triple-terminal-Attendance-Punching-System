交互逻辑汇总

  • 新建角色：点击"+ 新建角色"→ 列表取消选中 → 下方切换为创建表单 → 填写标识/名称/描述 + 勾选权限 → 点击"创建角色"
  • 修改角色：点击列表中某行 → 下方显示详情表单 → 修改名称/描述/权限 → 点击"保存修改"
  • 删除角色：选中角色 → 点击"删除角色" → ConfirmDialog 确认 → 调用 API
  • 系统角色保护：isSystem=true 的角色，角色标识字段只读，删除按钮禁用
  • 操作反馈：沿用现有 BusyOverlay + operationSucceeded/operationFailed 信号 + 操作后自动刷新列表
