# AttendanceAdmin - 考勤管理系统

## 项目概述

AttendanceAdmin 是一个基于 Qt 6 开发的桌面考勤管理系统客户端，用于管理和监控考勤设备、人员信息、考勤记录以及人脸识别数据。系统通过 TCP 协议与考勤设备服务端进行通信，提供完整的考勤管理解决方案。

## 版本信息

- **当前版本**: 0.1
- **Qt 版本要求**: 6.8+
- **C++ 标准**: C++17
- **构建系统**: CMake 3.16+

## 主要功能

### 1. 设备管理 (DeviceServer)
- 考勤设备的增删改查
- 设备状态监控（在线/离线）
- 设备命令下发
- 设备状态实时推送

### 2. 人员管理 (PersonServer)
- 员工信息管理（姓名、工号、部门、职位）
- 人员信息的增删改查
- 支持多维度查询筛选

### 3. 考勤管理 (AttendanceService)
- 考勤记录查询与管理
- 考勤记录创建、更新、删除
- 考勤归档管理
- 考勤数据导出

### 4. 人脸识别 (FaceServer)
- 人脸数据注册与更新
- 人脸信息查询
- 人脸特征删除
- 支持从本地图片文件注册

### 5. 用户管理 (UserServer)
- 系统用户账号管理
- 用户创建、查询、更新、删除

### 6. 权限管理 (RbacServer)
- 基于角色的访问控制 (RBAC)
- 角色管理（创建、更新、删除）
- 权限分配与撤销
- 用户角色管理

### 7. 配置部署 (ConfigDeployServer)
- 设备配置批量部署
- 配置版本管理
- 部署状态追踪

### 8. 事件订阅 (EventSubscriptionService)
- 设备状态实时推送
- 考勤记录实时推送
- 事件主题订阅管理

### 9. 会话管理 (SessionManager)
- 用户登录/登出
- JWT Token 管理
- 权限验证
- 会话状态维护

### 10. 日志服务 (LogWriter / FileService)
- 系统日志记录
- 日志文件管理

## 技术架构

### 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      QML UI 层                               │
│  (Main.qml, LoginPage, PageDashboard, PagePerson, etc.)     │
└─────────────────────────┬───────────────────────────────────┘
                          │
┌─────────────────────────▼───────────────────────────────────┐
│                    服务层 (C++ Services)                      │
│  SessionManager │ PersonServer │ DeviceServer │ ...          │
└─────────────────────────┬───────────────────────────────────┘
                          │
┌─────────────────────────▼───────────────────────────────────┐
│                   网络层 (TcpConnectionManager)               │
│          TCP 连接管理 │ 消息序列化 │ 心跳保活                  │
└─────────────────────────┬───────────────────────────────────┘
                          │
┌─────────────────────────▼───────────────────────────────────┐
│                    协议层 (Protocol)                          │
│              JSON 消息协议 │ 错误码定义                        │
└─────────────────────────────────────────────────────────────┘
```

### 通信协议

系统使用基于 JSON 的自定义协议进行通信，消息格式如下：

```json
{
  "type": "message.type",
  "msgId": "unique-message-id",
  "from": "client-id",
  "to": "server",
  "ts": 1234567890,
  "data": { ... }
}
```

### 主要消息类型

| 消息类型 | 说明 |
|---------|------|
| `auth` | 认证请求 |
| `auth_response` | 认证响应 |
| `heartbeat` | 心跳保活 |
| `person.create/query/update/delete` | 人员管理 |
| `device.create/query/update/delete` | 设备管理 |
| `attendance.create/query/update/delete` | 考勤管理 |
| `face.query/delete/register` | 人脸识别 |
| `user.create/query/update/delete` | 用户管理 |
| `role.create/query/update/delete` | 角色管理 |
| `config.deploy` | 配置部署 |
| `subscribe/unsubscribe` | 事件订阅 |

### 错误码定义

| 错误码 | 说明 |
|-------|------|
| 0 | 成功 |
| 1001 | 解析错误 |
| 1002 | 数据过大 |
| 2001 | 未认证 |
| 2002 | 认证失败 |
| 2003 | 重复会话 |
| 2004 | Token 无效 |
| 2005 | Token 过期 |
| 2006 | Refresh Token 无效 |
| 2007 | 权限不足 |
| 3001 | 禁止访问 |
| 4000 | 业务验证失败 |
| 4001 | 员工不存在 |
| 5001 | 设备离线 |
| 5002 | 转发超时 |
| 6001 | 重复键 |
| 6002 | 数据库错误 |

## 构建与运行

### 环境要求

- Qt 6.8 或更高版本
- CMake 3.16 或更高版本
- C++17 兼容的编译器
- Windows 10/11 (推荐)

### 构建步骤

```bash
# 1. 创建构建目录
mkdir build && cd build

# 2. 配置 CMake
cmake .. -G "Visual Studio 17 2022"

# 3. 编译项目
cmake --build . --config Release

# 4. 运行程序
./Release/AttendanceAdmin.exe
```

### Qt 组件依赖

- Qt6::Quick - QML 引擎
- Qt6::Core - 核心功能
- Qt6::Gui - 图形界面
- Qt6::Network - 网络通信
- Qt6::Widgets - 窗口部件
- Qt6::Charts - 图表展示

## 配置说明

### 连接配置

默认连接配置：
- **主机**: 127.0.0.1
- **端口**: 9527
- **客户端ID**: admin_001
- **心跳间隔**: 30秒
- **最大重连次数**: 10次
- **重连基础延迟**: 1000ms
- **请求超时**: 10000ms

## 开发说明

### 项目结构

详见 [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md)

### 添加新功能

1. 在 `src/` 下创建新的模块目录
2. 实现 Server 类（继承 QObject）
3. 在 `main.cpp` 中注册服务
4. 在 `CMakeLists.txt` 中添加源文件
5. 创建对应的 QML 页面

### 代码规范

- 使用 Qt 命名约定
- 信号/槽使用 Qt5 风格
- 使用 `Q_INVOKABLE` 暴露方法给 QML
- 使用 `Q_PROPERTY` 实现属性绑定
