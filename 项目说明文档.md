# AttendanceSystem 设备端项目结构说明文档

## 一、项目概述

### 1.1 项目简介

AttendanceSystem 是一个基于 Qt 的人脸识别考勤设备端应用，主要功能包括：
- 人脸检测与识别
- 考勤规则判定
- 打卡记录上报
- 离线数据缓存
- 远程配置同步

### 1.2 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Qt | 6.x | GUI框架、网络、多媒体、数据库 |
| C++ | 17 | 主要开发语言 |
| SQLite | 3.x | 本地数据存储 |
| ArcFace SDK | - | 人脸识别引擎 |
| CMake | 3.16+ | 构建系统 |

```
┌─────────────────────────────────────────────────────────────────────┐
│                    人脸识别模块架构                                   │
├─────────────────────────────────────────────────────────────────────┤

│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**核心类说明：**

| 类名 | 文件 | 职责 |
|------|------|------|
| `FaceRecognizer` | FaceRecognition/facerecognizer.h | 状态机驱动的人脸识别流程控制 |
| `ArcFaceEngine` | FaceRecognition/arcfaceengine.h | ArcFace SDK 封装，提供检测、提取、比对 |
| `FaceDatabaseManager` | FaceRecognition/facedatabasemanager.h | 内存特征库管理，从数据库加载特征 |

**状态机流程：**

```
IDLE (空闲) ──检测到人脸──▶ DETECTING (识别中)
    ▲                           │
    │                           ▼
    │                    RECOGNIZED (已识别，冷却)
    │                           │
    │                           ▼
    └────── 冷却结束 ◀──── LOST (人脸丢失)
```

### 5.2 配置项说明

**config.ini (可远程覆盖)：**

```ini
[FaceRecognition]
FaceThreshold=80        # 人脸相似度阈值 (0-100)
MaxFaceCount=5          # 最大人脸数
CameraRotation=0        # 摄像头旋转角度

[Attendance]
WorkStartTime=09:00     # 上班时间
WorkEndTime=18:00       # 下班时间
LateAllowance=15        # 迟到容忍 (分钟)
EarlyLeaveAllowance=15  # 早退容忍 (分钟)
MinCheckInterval=60     # 最小打卡间隔 (秒)

[Device]
DeviceId=device_001     # 设备ID
DeviceKey=xxx           # 设备密钥
```

**local.ini (本机配置)：**

```ini
[Network]
ServerIP=192.168.1.100  # 服务器IP
ServerPort=8080         # 服务器端口

[MainWindow]
Width=1200              # 窗口宽度
Height=800              # 窗口高度
```
