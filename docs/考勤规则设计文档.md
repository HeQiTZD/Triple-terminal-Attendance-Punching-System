# 考勤规则设计文档

## 一、概述

### 1.1 文档目的

本文档定义了设备端考勤系统的打卡规则逻辑，包括迟到、早退、缺勤等状态的判定算法，以及考勤规则引擎的实现方案。

### 1.2 项目路径

| 项目 | 路径 | 技术栈 |
|------|------|--------|
| 设备端 | `D:\QTproject\AttendanceSystem` | Qt 6 C++ |

## 二、考勤状态定义

### 2.1 状态值定义

| 状态值 | 含义 | 判定条件 |
|--------|------|----------|
| `normal` | 正常 | 在规定打卡范围内打卡 |
| `late` | 迟到 | 实际打卡时间 > 打卡截止时间 + 迟到宽限时间 |
| `early` | 早退 | 实际打卡时间 < 下班打卡开始时间 |
| `absent` | 缺勤 | 当天无有效打卡记录（服务端计算） |

### 3.3 配置参数说明

#### 3.3.1 基础时间参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `workStartTime` | Time | 09:00 | 规定上班时间，也是打卡截止时间 |
| `workEndTime` | Time | 18:00 | 规定下班时间，也是打卡开始时间 |

#### 3.3.2 打卡范围参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `checkInStartOffset` | int | 120 | 上班打卡开始时间偏移（分钟），如 07:00 开始可以打上班卡 |
| `lateAllowance` | int | 15 | 迟到宽限时间（分钟），09:15 前打卡不算迟到 |
| `earlyLeaveAllowance` | int | 15 | 早退宽限时间（分钟） |
| `checkOutEndOffset` | int | 180 | 下班打卡截止时间偏移（分钟），21:00 后不能打下班卡 |

#### 3.3.3 弹性工时参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `flexibleWorkEnabled` | bool | false | 是否启用弹性工时 |
| `flexibleRange` | int | 30 | 弹性范围（分钟），可前后浮动 |
| `coreWorkStart` | Time | 10:00 | 核心工作时段开始 |
| `coreWorkEnd` | Time | 16:00 | 核心工作时段结束 |

#### 3.3.4 午休时间参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `lunchBreakEnabled` | bool | true | 是否扣除午休时间 |
| `lunchBreakStart` | Time | 12:00 | 午休开始时间 |
| `lunchBreakEnd` | Time | 13:00 | 午休结束时间 |

#### 3.3.5 异常处理参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `minCheckInterval` | int | 60 | 重复打卡最小间隔（秒） |
| `allowCrossDay` | bool | false | 是否允许跨天打卡 |
| `maxWorkHours` | int | 12 | 最大工作时长（小时） |

#### 5.3.2 核心算法实现

```cpp
CheckResult AttendanceRuleEngine::evaluate(const QDateTime& checkTime) {
    CheckResult result;
    QTime timeOfDay = checkTime.time();
    
    ConfigManager* config = ConfigManager::instance();
    
    QTime workStart = config->getWorkStartTime();
    QTime workEnd = config->getWorkEndTime();
    int lateAllowance = config->getLateAllowance();
    int checkInStartOffset = config->getCheckInStartOffset();
    int checkOutEndOffset = config->getCheckOutEndOffset();
    
    QTime checkInStart = workStart.addSecs(-checkInStartOffset * 60);
    QTime checkInDeadline = workStart.addSecs(lateAllowance * 60);
    QTime checkOutStart = workEnd;
    QTime checkOutEnd = workEnd.addSecs(checkOutEndOffset * 60);
    
    if (timeOfDay >= checkInStart && timeOfDay <= checkInDeadline) {
        if (timeOfDay <= workStart) {
            result.status = "normal";
            result.message = "打卡成功";
        } else {
            result.status = "late";
            result.lateMinutes = calculateLateMinutes(timeOfDay, workStart);
            result.message = QString("迟到 %1 分钟").arg(result.lateMinutes);
        }
        result.isValid = true;
    }
    else if (timeOfDay >= checkOutStart && timeOfDay <= checkOutEnd) {
        if (timeOfDay >= workEnd) {
            result.status = "normal";
            result.message = "打卡成功";
        } else {
            result.status = "early";
            result.earlyMinutes = calculateEarlyMinutes(timeOfDay, workEnd);
            result.message = QString("早退 %1 分钟").arg(result.earlyMinutes);
        }
        result.isValid = true;
    }
    else if (timeOfDay > checkInDeadline && timeOfDay < checkOutStart) {
        result.status = "normal";
        result.isValid = true;
        result.message = "补打卡";
    }
    else {
        result.isValid = false;
        result.message = "不在有效打卡时间范围内";
    }
    
    return result;
}

int AttendanceRuleEngine::calculateLateMinutes(const QTime& checkTime, 
                                                const QTime& deadline) const {
    return deadline.secsTo(checkTime) / 60;
}

int AttendanceRuleEngine::calculateEarlyMinutes(const QTime& checkTime, 
                                                 const QTime& startTime) const {
    return checkTime.secsTo(startTime) / 60;
}
```

#### 5.3.3 弹性工时算法

```cpp
CheckResult AttendanceRuleEngine::evaluateFlexible(const QDateTime& checkTime) {
    CheckResult result;
    QTime timeOfDay = checkTime.time();
    
    ConfigManager* config = ConfigManager::instance();
    
    if (!config->isFlexibleWorkEnabled()) {
        return evaluateStandard(checkTime);
    }
    
    QTime coreStart = config->getCoreWorkStart();
    QTime coreEnd = config->getCoreWorkEnd();
    int flexibleRange = config->getFlexibleRange();
    
    QTime flexStart = config->getWorkStartTime().addSecs(-flexibleRange * 60);
    QTime flexEnd = config->getWorkEndTime().addSecs(flexibleRange * 60);
    
    if (timeOfDay >= flexStart && timeOfDay <= coreEnd) {
        result.status = "normal";
        result.isValid = true;
        result.message = "弹性打卡成功";
    }
    else if (timeOfDay >= coreStart && timeOfDay <= flexEnd) {
        result.status = "normal";
        result.isValid = true;
        result.message = "弹性打卡成功";
    }
    else {
        result.isValid = false;
        result.message = "不在弹性工时打卡范围内";
    }
    
    return result;
}
```

```cpp
bool AttendanceConfigSyncHandler::saveToFile(const QJsonObject& config) {
    QString filePath = getConfigFilePath();
    
    QDir dir = QFileInfo(filePath).dir();
    if (!dir.exists()) {
        dir.mkpath(".");
    }
    
    QString backupPath = filePath + ".bak";
    if (QFile::exists(filePath)) {
        QFile::remove(backupPath);
        QFile::copy(filePath, backupPath);
    }
    
    QJsonDocument doc(config);
    QFile file(filePath);
    if (!file.open(QIODevice::WriteOnly)) {
        return false;
    }
    
    file.write(doc.toJson(QJsonDocument::Indented));
    file.close();
    return true;
}

QJsonObject AttendanceConfigSyncHandler::loadFromFile() const {
    QString filePath = getConfigFilePath();
    
    QFile file(filePath);
    if (!file.open(QIODevice::ReadOnly)) {
        return QJsonObject();
    }
    
    QJsonDocument doc = QJsonDocument::fromJson(file.readAll());
    file.close();
    
    return doc.object();
}
```

```cpp
bool AttendanceConfigSyncHandler::verifyChecksum(const QJsonObject& config) const {
    QString receivedChecksum = config["checksum"].toString();
    QString calculatedChecksum = calculateChecksum(config["config"].toObject());
    return receivedChecksum == calculatedChecksum;
}

bool AttendanceConfigSyncHandler::verifySignature(const QJsonObject& config) const {
    QString signature = config["signature"].toString();
    QByteArray data = QJsonDocument(config["config"].toObject()).toJson();
    return RsaVerifier::verify(data, signature);
}
```

## 八、特殊情况处理

### 8.1 重复打卡处理

```
场景：员工在短时间内多次打卡

处理逻辑：
1. 检查该员工最近一次打卡时间
2. 如果间隔 < minCheckInterval（默认60秒）
   - 判定为重复打卡
   - 忽略本次打卡，返回上次打卡结果
3. 否则，正常处理本次打卡
```

```cpp
bool AttendanceRuleEngine::isDuplicateCheck(
    const QString& employeeId, 
    const QDateTime& checkTime) const 
{
    QDateTime lastCheck = DatabaseManager::instance()->getLastCheckTime(employeeId);
    if (!lastCheck.isValid()) {
        return false;
    }
    
    int interval = ConfigManager::instance()->getMinCheckInterval();
    return lastCheck.secsTo(checkTime) < interval;
}
```

### 8.2 跨天打卡处理

```
场景：夜班员工下班时间跨过午夜

配置：allowCrossDay = true

处理逻辑：
1. 如果员工在 00:00-06:00 打卡
2. 检查前一天是否有上班打卡记录
3. 如果有，本次打卡视为前一天的下班打卡
4. 如果没有，视为当天的上班打卡
```

### 8.3 加班处理

```
场景：员工加班到很晚

处理逻辑：
1. 检测下班打卡时间超过 maxWorkHours
2. 自动计算加班时长
3. 打卡状态仍为 "normal"
4. 加班时长单独记录，用于调休计算
```

## 十一、异常处理机制

### 11.1 异常类型定义

| 异常类型 | 错误码 | 说明 | 处理方式 |

| `RULE_NOT_LOADED` | 1005 | 规则未加载 | 使用默认规则 |
