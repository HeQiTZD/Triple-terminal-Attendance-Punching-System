## 1. 设计 Token

### 1.1 色彩

```

  primarySubtle     #DBEAFE   浅蓝背景、权限标签

  bg                #F2F4F7   页面底色

  sideBar           #E8EBF1   侧边栏

  borderStrong      #B0B8C4   强调边框

Text（文字层级）
  text              #1F2937   正文
  textMuted         #3D4551   次要文字（原 #4B5563 → 加深以满足 4.5:1）

Shadow（阴影 — 待实现）
  shadowLight       rgba(0,0,0,0.06)
```

### 2.1 路由表

| Key | 页面 | 所需权限 | 说明 |
|-----|------|---------|------|
| `dashboard` | 仪表盘 | 无（默认） | 统计卡片 + 打卡记录 + 考勤饼图 |
| `person` | 人员管理 | `person.read` | 人员 CRUD + 列表 |
| `device` | 设备管理 | `device.read` | 设备 CRUD + 指令下发 |
| `configDeploy` | 配置下发 | `config.deploy` | INI 构建器 + 设备选择 + 分发 |
| `attendance` | 考勤记录 | `attendance.read` | 实时打卡 / 归档记录双 Tab |
| `face` | 人脸库 | `face.read` | 人脸查询 + 注册 + 删除 |
| `user` | 用户账号 | `user.read` | 用户 CRUD |
| `rbac` | 用户权限 | `super_admin` 角色 | 用户-角色分配面板 |

```
              ┌──────────────────────────────┐
              │                    [⚙] [✕]   │  ← 设置按钮 / 关闭按钮 (右上)
              │                              │
              │       考勤管理系统            │  ← 标题 18px bold
              │                              │
              │   ┌──────────────────────┐   │
              │   │ 工号 / 用户名         │   │  ← LabeledField
              │   │ [___________________] │   │  ← TextField, placeholder "请输入用户名或工号"
              │   │                      │   │
              │   │ 密码                 │   │
              │   │ [___________________] │   │  ← Password echo, Enter 触发登录
              │   └──────────────────────┘   │
              │                              │
              │        [ 登录 ]              │  ← Primary Button, 160×30
              │                              │
              │      ⚠ 错误提示文字           │  ← danger 色, 仅出错时显示
              └──────────────────────────────┘
                        400 × 542
```

### 交互细节

| 状态 | 行为 |
|------|------|
| 默认 | 输入框可用，登录按钮 disabled（用户/密码为空时） |
| 输入中 | 按钮 enabled（两项均非空时） |
| 登录中 | 按钮文字 → "登录中…"，disabled，输入框 disabled |
| 登录成功 | 窗口切换至主界面 (1480×920) |
| 登录失败 | 红色错误文字显示，按钮恢复 |
| 连接断开 | "未连接服务器" 提示 |

## 9. 图标系统

> **当前问题**: 导航栏使用 emoji（◆👤⬡⇪📋◎🔑🛡），跨平台渲染不一致。
> **解决方案**: 使用 Unicode 符号替代 emoji，或引入矢量图标字体。

### 9.1 导航图标映射

| 页面 | 当前 Emoji | 替换方案 | Unicode |
|------|-----------|---------|---------|
| 仪表盘 | ◆ | 菱形/网格 | `◈` 或 `⊞` |
| 人员管理 | 👤 | 人物轮廓 | `👤` (保留，最广泛支持) |
| 设备管理 | ⬡ | 六边形/终端 | `⬢` 或 `⎔` |
| 配置下发 | ⇪ | 上传/火箭 | `⬆` 或 `⚙` |
| 考勤记录 | 📋 | 剪贴板 | `📋` (保留) |
| 人脸库 | ◎ | 同心圆/目标 | `◎` 或 `⊙` |
| 用户账号 | 🔑 | 钥匙 | `🔑` (保留) |
| 用户权限 | 🛡 | 盾牌 | `🛡` (保留) |

> **长期方案**: 引入 Qt `icon.image` 或 SVG 图标系统（如 Material Design Icons）。

### 9.2 状态图标

| Loading 出现 | 200ms | ease-out | 淡入 + 旋转 |

- 遮罩: `rgba(255, 255, 255, 0.7)`
- 指示器: Qt Quick `BusyIndicator`, accent 色
