## 1. 设计概述

### 1.1 设计理念

基于 **Data-Dense Dashboard** 设计风格，打造专业、高效的企业级考勤管理系统。

**核心设计原则**：
- **效率优先**：减少操作步骤，提升 HR 工作效率
- **数据可视化**：清晰呈现考勤数据，支持快速决策
- **一致性**：统一交互模式，降低学习成本
- **可访问性**：符合 WCAG AA 标准，支持暗色模式

### 1.2 设计系统配置

| 配置项 | 说明 |
|--------|------|
| **设计风格** | Data-Dense Dashboard |
| **模式支持** | ✓ 浅色模式 ✓ 深色模式 |
| **关键词** | 数据表格、KPI 卡片、最小间距、网格布局、空间高效 |
| **适用场景** | 企业管理、运营仪表盘、数据报表 |
| **性能** | ⚡ 优秀 |
| **可访问性** | ✓ WCAG AA |

## 3. 字体系统

### 3.1 字体选择

**主字体**: Plus Jakarta Sans

**选择理由**：
- 专业、现代、易读
- 适合企业级应用和管理仪表盘
- 支持多种字重（400/600/700/800）
- 良好的屏幕显示效果

**Google Fonts**: [Plus Jakarta Sans](https://fonts.google.com/share?selection.family=Plus+Jakarta+Sans:ital,wght@0,400;0,600;0,700;0,800;1,400)

**备用字体**: Segoe UI, Microsoft YaHei UI, PingFang SC, sans-serif

### 3.2 字体规格

| 层级 | 字重 | 大小 | 行高 | 用途 |
|------|------|------|------|------|
| **H1** | 800 | 32px | 1.2 | 页面标题 |
| **H2** | 700 | 24px | 1.3 | 模块标题 |
| **H3** | 700 | 20px | 1.4 | 卡片标题 |

## 5. 组件设计规范

### 5.1 按钮组件

#### 主要按钮 (Primary)
```
┌─────────────────────┐
│  ✓ 操作名称         │  ← 主要操作（保存、提交、新增）
└─────────────────────┘

样式：
- 背景: --color-accent (#22C55E)
- 文字: #FFFFFF
- 圆角: --radius-md (8px)
- 高度: 40px
- 内边距: 12px 24px
- 悬停: 亮度降低 10%
- 按下: 亮度降低 20%
- 禁用: 透明度 50%
```

#### 次要按钮 (Secondary)
```
┌─────────────────────┐
│  操作名称            │  ← 次要操作（取消、返回）
└─────────────────────┘

样式：
- 背景: transparent
- 边框: 1px solid --color-border
- 文字: --color-foreground
- 悬停: 背景 --color-muted
```

#### 危险按钮 (Destructive)
```
┌─────────────────────┐
│  🗑 删除             │  ← 危险操作（删除、清空）
└─────────────────────┘

样式：
- 背景: --color-destructive (#EF4444)
- 文字: #FFFFFF
- 需要二次确认
```

#### 图标按钮
```
┌────┐
│ 📋 │  ← 工具栏操作
└────┘

样式：
- 尺寸: 36×36px
- 圆角: --radius-md
- 悬停: 背景 --color-muted
- 必须有 tooltip
```

### 5.4 通知组件 (Toast)

```
┌─────────────────────────────────────────┐
│  ✓ 操作成功！人员信息已保存             │
└─────────────────────────────────────────┘

位置：页面顶部居中
自动消失：3 秒
可手动关闭：× 按钮
```

**四种类型**：

| 类型 | 图标 | 颜色 | 用途 |
|------|------|------|------|
| **Success** | ✓ | `#22C55E` | 操作成功 |
| **Error** | ✗ | `#EF4444` | 操作失败 |
| **Warning** | ⚠ | `#F59E0B` | 警告提示 |
| **Info** | ℹ | `#3B82F6` | 信息提示 |

**动画**：
- 进入：从顶部滑入 + 淡入（200ms）
- 退出：淡出（150ms）

### 5.5 模态框组件

```
┌─────────────────────────────────────────┐
│  标题                            [×]    │
├─────────────────────────────────────────┤
│                                         │
│  内容区域                               │
│                                         │
├─────────────────────────────────────────┤
│                    [取消]  [确认]        │
└─────────────────────────────────────────┘

样式：
- 背景遮罩: rgba(0,0,0,0.5)
- 圆角: --radius-lg (12px)
- 最大宽度: 480px
- 阴影: 大阴影
- 动画: 缩放 + 淡入（200ms）
```

### 5.6 表单验证

**实时验证规则**：
- 输入时：不显示错误（避免干扰）
- 失焦时：显示验证结果
- 提交前：汇总所有错误

**错误提示样式**：
```
用户名 *
┌─────────────────────────────────┐
│                                 │  ← 红色边框
└─────────────────────────────────┘
  用户名不能为空                    ← 红色文字 (12px)
```

**验证状态指示**：
- 未验证：默认边框
- 验证通过：绿色边框 + ✓ 图标
- 验证失败：红色边框 + 错误提示

## 7. 暗色模式设计

### 7.1 切换机制

**入口位置**：状态栏右侧（太阳/月亮图标）

**切换动画**：
- 所有颜色过渡：200ms ease
- 避免闪烁：使用 CSS 变量

**持久化**：
- 保存用户选择到本地存储
- 下次启动自动应用

### 7.2 暗色模式色彩映射

| 元素 | 浅色模式 | 暗色模式 |
|------|----------|----------|
| 页面背景 | `#F8FAFC` | `#020617` |
| 卡片背景 | `#FFFFFF` | `#1E293B` |
| 主文字 | `#0F172A` | `#F8FAFC` |
| 次要文字 | `#64748B` | `#94A3B8` |
| 边框 | `#E2E8F0` | `#334155` |
| 输入框背景 | `#FFFFFF` | `#0F172A` |
| 悬停背景 | `#F1F5F9` | `#334155` |

### 7.3 对比度检查

- 主文字对比度：≥ 4.5:1
- 次要文字对比度：≥ 3:1
- 图标对比度：≥ 3:1

## 8. 动画规范

### 8.1 过渡时间

| 类型 | 时间 | 缓动 | 用途 |
|------|------|------|------|
| 微交互 | 150ms | ease-out | 按钮悬停、状态切换 |
| 状态变化 | 200ms | ease-in-out | 主题切换、展开收起 |
| 页面过渡 | 300ms | ease-in-out | 模态框、通知 |

### 8.2 动画效果

**按钮悬停**：
- 背景色变化（150ms）
- 轻微阴影提升

**表格行悬停**：
- 背景色高亮（150ms）
- 光标变为 pointer

**通知进入**：
- 从顶部滑入（200ms）
- 淡入效果

**模态框打开**：
- 缩放 0.95 → 1（200ms）
- 背景遮罩淡入

**侧边栏展开/收起**：
- 宽度变化（200ms）
- 内容淡入淡出
