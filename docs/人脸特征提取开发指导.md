# 人脸特征提取模块开发指导文档

## 一、概述

本文档指导开发者如何在独立项目中集成人脸特征提取功能，实现从传入的图片提取人脸特征向量。基于虹软（ArcSoft）ArcFace SDK 实现。

### 1.1 功能目标

- 从图片中检测人脸位置
- 提取人脸特征向量（用于后续比对）
- 计算两张人脸的相似度

### 1.2 技术选型

| 组件 | 说明 |
|------|------|
| SDK | 虹软 ArcFace 人脸识别 SDK |
| 语言 | C++ |
| 框架 | Qt 5.15+ / Qt 6.x |
| 编译 | CMake |

### 1.3 适用场景

- 人脸考勤系统
- 人脸门禁系统
- 人脸登录验证
- 人脸照片分类管理

## 二、快速开始

### 2.1 最简使用示例

```cpp
#include "arcfaceengine.h"

int main()
{
    ArcFaceEngine* engine = ArcFaceEngine::instance();
    
    if (!engine->initialize("your_app_id", "your_sdk_key")) {
        return -1;
    }
    
    QImage image("photo.jpg");
    auto faces = engine->detectFace(image);
    
    if (!faces.isEmpty()) {
        auto feature = engine->extractFeature(image, faces[0]);
        qDebug() << "特征提取成功，大小:" << feature.size << "字节";
    }
    
    engine->uninitialize();
    return 0;
}
```

## 四、核心代码实现

### 4.1 引擎头文件

```cpp
#ifndef ARCFACEENGINE_H
#define ARCFACEENGINE_H

#include <QObject>
#include <QRect>
#include <QImage>
#include <QVector>
#include <QByteArray>
#include <QMutex>

#include "arcsoft_face_sdk.h"
#include "merror.h"

class ArcFaceEngine
{
public:
    struct FaceInfo {
        QRect rect;
        int orient;
        int faceId;
    };

    struct FaceFeature {
        QByteArray data;
        int size;
        bool isValid() const { return size > 0 && !data.isEmpty(); }
    };

    static ArcFaceEngine* instance();

    bool initialize(const QString &appId, const QString &sdkKey);
    void uninitialize();
    bool isInitialized() const;

    QVector<FaceInfo> detectFace(const QImage &image);
    FaceFeature extractFeature(const QImage &image, const FaceInfo &faceInfo);
    float compareFeatures(const FaceFeature &feature1, const FaceFeature &feature2);

private:
    ArcFaceEngine();
    ~ArcFaceEngine();
    ArcFaceEngine(const ArcFaceEngine&) = delete;
    ArcFaceEngine& operator=(const ArcFaceEngine&) = delete;

    QImage preprocessImage(const QImage &image);

    MHandle m_engine;
    bool m_initialized;
    QImage m_convertedImage;

    static QMutex s_mutex;
    static ArcFaceEngine* s_instance;
};

#endif
```

### 4.2 引擎实现文件

```cpp
#include "arcfaceengine.h"
#include <QDebug>

ArcFaceEngine* ArcFaceEngine::s_instance = nullptr;
QMutex ArcFaceEngine::s_mutex;

ArcFaceEngine::ArcFaceEngine() 
    : m_engine(nullptr), m_initialized(false) 
{
}

ArcFaceEngine::~ArcFaceEngine()
{
    uninitialize();
}

ArcFaceEngine* ArcFaceEngine::instance()
{
    if (!s_instance) {
        QMutexLocker locker(&s_mutex);
        if (!s_instance) {
            s_instance = new ArcFaceEngine();
        }
    }
    return s_instance;
}

bool ArcFaceEngine::initialize(const QString &appId, const QString &sdkKey)
{
    if (m_initialized) {
        return true;
    }

    MRESULT result = ASFOnlineActivation(
        appId.toLocal8Bit().data(), 
        sdkKey.toLocal8Bit().data()
    );
    
    if (MOK != result && MERR_ASF_ALREADY_ACTIVATED != result) {
        qWarning() << "SDK激活失败，错误码：" << result;
        return false;
    }

    MInt32 combinedMask = ASF_FACE_DETECT | ASF_FACERECOGNITION;
    
    result = ASFInitEngine(
        ASF_DETECT_MODE_IMAGE,
        ASF_OP_0_ONLY,
        32,
        10,
        combinedMask, 
        &m_engine
    );
    
    if (result != MOK) {
        qWarning() << "引擎初始化失败，错误码：" << result;
        return false;
    }

    m_initialized = true;
    qDebug() << "人脸识别引擎初始化成功";
    return true;
}

void ArcFaceEngine::uninitialize()
{
    if (m_initialized && m_engine) {
        ASFUninitEngine(m_engine);
        m_engine = nullptr;
        m_initialized = false;
        qDebug() << "人脸识别引擎已释放";
    }
}

bool ArcFaceEngine::isInitialized() const
{
    return m_initialized;
}

QImage ArcFaceEngine::preprocessImage(const QImage &image)
{
    QImage tempImage = image.convertToFormat(QImage::Format_RGB888);
    
    m_convertedImage = QImage(tempImage.size(), QImage::Format_RGB888);
    for (int y = 0; y < tempImage.height(); ++y) {
        const uchar* srcLine = tempImage.scanLine(y);
        uchar* dstLine = m_convertedImage.scanLine(y);
        for (int x = 0; x < tempImage.width(); ++x) {
            dstLine[x * 3 + 0] = srcLine[x * 3 + 2];
            dstLine[x * 3 + 1] = srcLine[x * 3 + 1];
            dstLine[x * 3 + 2] = srcLine[x * 3 + 0];
        }
    }

    int alignedWidth = (m_convertedImage.width() / 4) * 4;
    if (alignedWidth != m_convertedImage.width()) {
        m_convertedImage = m_convertedImage.copy(
            0, 0, alignedWidth, m_convertedImage.height()
        );
    }
    
    return m_convertedImage;
}

QVector<ArcFaceEngine::FaceInfo> ArcFaceEngine::detectFace(const QImage &image)
{
    QVector<FaceInfo> faceInfos;
    
    if (!m_initialized) {
        qWarning() << "引擎未初始化";
        return faceInfos;
    }
    if (image.isNull()) {
        qWarning() << "输入图像为空";
        return faceInfos;
    }

    preprocessImage(image);

    ASVLOFFSCREEN asvl = {0};
    asvl.u32PixelArrayFormat = ASVL_PAF_RGB24_B8G8R8;
    asvl.i32Width = m_convertedImage.width();
    asvl.i32Height = m_convertedImage.height();
    asvl.ppu8Plane[0] = m_convertedImage.bits();
    asvl.pi32Pitch[0] = m_convertedImage.bytesPerLine();

    ASF_MultiFaceInfo detectedFaces = {0};
    MRESULT result = ASFDetectFacesEx(m_engine, &asvl, &detectedFaces, ASF_DETECT_MODEL_RGB);

    if (result != MOK) {
        qWarning() << "人脸检测失败，错误码：" << result;
        return faceInfos;
    }

    for (MInt32 i = 0; i < detectedFaces.faceNum; ++i) {
        FaceInfo info;
        info.rect = QRect(
            detectedFaces.faceRect[i].left,
            detectedFaces.faceRect[i].top,
            detectedFaces.faceRect[i].right - detectedFaces.faceRect[i].left,
            detectedFaces.faceRect[i].bottom - detectedFaces.faceRect[i].top
        );
        info.orient = detectedFaces.faceOrient[i];
        info.faceId = detectedFaces.faceID ? detectedFaces.faceID[i] : -1;
        faceInfos.append(info);
    }

    return faceInfos;
}

ArcFaceEngine::FaceFeature ArcFaceEngine::extractFeature(
    const QImage &image, 
    const FaceInfo &faceInfo)
{
    FaceFeature feature;

    if (!m_initialized || image.isNull()) {
        return feature;
    }

    preprocessImage(image);

    ASVLOFFSCREEN asvl = {0};
    asvl.u32PixelArrayFormat = ASVL_PAF_RGB24_B8G8R8;
    asvl.i32Width = m_convertedImage.width();
    asvl.i32Height = m_convertedImage.height();
    asvl.ppu8Plane[0] = m_convertedImage.bits();
    asvl.pi32Pitch[0] = m_convertedImage.bytesPerLine();

    ASF_SingleFaceInfo singleFaceInfo = {0};
    singleFaceInfo.faceRect.left = faceInfo.rect.left();
    singleFaceInfo.faceRect.top = faceInfo.rect.top();
    singleFaceInfo.faceRect.right = faceInfo.rect.right();
    singleFaceInfo.faceRect.bottom = faceInfo.rect.bottom();
    singleFaceInfo.faceOrient = faceInfo.orient;

    ASF_FaceFeature sdkFeature = {0};
    MRESULT result = ASFFaceFeatureExtractEx(m_engine, &asvl, &singleFaceInfo, &sdkFeature);

    if (result != MOK) {
        qWarning() << "特征提取失败，错误码：" << result;
        return feature;
    }

    feature.size = sdkFeature.featureSize;
    feature.data = QByteArray(
        reinterpret_cast<char*>(sdkFeature.feature), 
        sdkFeature.featureSize
    );

    return feature;
}

float ArcFaceEngine::compareFeatures(
    const FaceFeature &feature1, 
    const FaceFeature &feature2)
{
    if (!m_initialized || !feature1.isValid() || !feature2.isValid()) {
        return 0.0f;
    }

    ASF_FaceFeature sdkFeature1 = {0};
    sdkFeature1.feature = reinterpret_cast<MByte*>(
        const_cast<char*>(feature1.data.data())
    );
    sdkFeature1.featureSize = feature1.size;

    ASF_FaceFeature sdkFeature2 = {0};
    sdkFeature2.feature = reinterpret_cast<MByte*>(
        const_cast<char*>(feature2.data.data())
    );
    sdkFeature2.featureSize = feature2.size;

    MFloat confidence = 0.0f;
    MRESULT result = ASFFaceFeatureCompare(
        m_engine,
        &sdkFeature1,
        &sdkFeature2,
        &confidence,
        ASF_LIFE_PHOTO
    );

    if (result != MOK) {
        qWarning() << "特征对比失败，错误码：" << result;
        return 0.0f;
    }

    return confidence;
}
```

## 五、使用示例

### 5.1 基本使用流程

```cpp
#include "arcfaceengine.h"

int main()
{
    ArcFaceEngine* engine = ArcFaceEngine::instance();
    
    if (!engine->initialize("your_app_id", "your_sdk_key")) {
        qDebug() << "初始化失败";
        return -1;
    }

    QImage image("photo.jpg");
    if (image.isNull()) {
        qDebug() << "图像加载失败";
        return -1;
    }

    QVector<ArcFaceEngine::FaceInfo> faces = engine->detectFace(image);
    if (faces.isEmpty()) {
        qDebug() << "未检测到人脸";
        return -1;
    }

    ArcFaceEngine::FaceFeature feature = engine->extractFeature(image, faces[0]);
    if (feature.isValid()) {
        qDebug() << "特征提取成功，大小:" << feature.size << "字节";
    }

    engine->uninitialize();
    return 0;
}
```

### 5.2 人脸比对示例

```cpp
bool compareTwoFaces(const QString &imagePath1, const QString &imagePath2)
{
    ArcFaceEngine* engine = ArcFaceEngine::instance();
    
    QImage image1(imagePath1);
    QImage image2(imagePath2);
    
    auto faces1 = engine->detectFace(image1);
    auto faces2 = engine->detectFace(image2);
    
    if (faces1.isEmpty() || faces2.isEmpty()) {
        qDebug() << "图像中未检测到人脸";
        return false;
    }
    
    auto feature1 = engine->extractFeature(image1, faces1[0]);
    auto feature2 = engine->extractFeature(image2, faces2[0]);
    
    float similarity = engine->compareFeatures(feature1, feature2);
    
    qDebug() << "相似度:" << similarity;
    
    return similarity >= 0.8f;
}
```

### 5.3 人脸注册与识别示例

```cpp
struct PersonFeature {
    QString personId;
    QString name;
    ArcFaceEngine::FaceFeature feature;
};

QVector<PersonFeature> featureDatabase;

bool registerFace(const QString &personId, const QString &name, const QString &imagePath)
{
    ArcFaceEngine* engine = ArcFaceEngine::instance();
    
    QImage image(imagePath);
    auto faces = engine->detectFace(image);
    
    if (faces.isEmpty()) {
        qDebug() << "未检测到人脸";
        return false;
    }
    
    PersonFeature record;
    record.personId = personId;
    record.name = name;
    record.feature = engine->extractFeature(image, faces[0]);
    
    if (!record.feature.isValid()) {
        qDebug() << "特征提取失败";
        return false;
    }
    
    featureDatabase.append(record);
    return true;
}

QString recognizeFace(const QImage &image, float &bestSimilarity)
{
    ArcFaceEngine* engine = ArcFaceEngine::instance();
    
    auto faces = engine->detectFace(image);
    if (faces.isEmpty()) {
        return QString();
    }
    
    auto targetFeature = engine->extractFeature(image, faces[0]);
    if (!targetFeature.isValid()) {
        return QString();
    }
    
    QString bestMatch;
    bestSimilarity = 0.0f;
    
    for (const auto &record : featureDatabase) {
        float similarity = engine->compareFeatures(targetFeature, record.feature);
        if (similarity > bestSimilarity) {
            bestSimilarity = similarity;
            bestMatch = record.personId;
        }
    }
    
    if (bestSimilarity < 0.8f) {
        return QString();
    }
    
    return bestMatch;
}
```

## 七、相似度阈值参考

| 阈值范围 | 判定结果 | 应用场景 |
|----------|----------|----------|
| ≥ 0.85 | 极可能是同一人 | 高安全要求场景 |
| 0.75 - 0.85 | 很可能是同一人 | 一般考勤场景 |
| 0.6 - 0.75 | 可能是同一人 | 低安全要求场景 |
| < 0.6 | 不太可能是同一人 | 拒绝识别 |

**建议**：考勤系统推荐使用 0.8 作为阈值。

## 八、注意事项

### 8.1 图像预处理

SDK 要求图像满足以下条件：

1. **颜色格式**：BGR 顺序（需从 RGB 转换）
2. **宽度对齐**：宽度必须是 4 的倍数
3. **格式要求**：RGB888 格式

预处理代码已封装在 `preprocessImage()` 方法中。

### 8.2 线程安全

- 引擎使用单例模式，内部有互斥锁保护
- 多线程环境下，建议在外部加锁保护连续调用

### 8.3 图像要求

- **格式**：支持 RGB888、RGB32、ARGB32、灰度图
- **尺寸**：人脸尺寸建议不小于 80x80 像素
- **质量**：图像清晰、光线充足、正脸效果最佳

### 8.4 内存管理

- 特征数据使用 `QByteArray` 自动管理内存
- 引擎在析构时自动释放 SDK 资源

## 九、常见问题

### Q1: 检测不到人脸？

**原因**：
- 图像质量差、模糊
- 人脸尺寸过小
- 光线不足或过曝
- 人脸角度过大

**解决方案**：
- 提高图像分辨率
- 调整 `minFaceSize` 参数（默认32，可调小）
- 改善光照条件

### Q2: 特征提取失败？

**原因**：
- 引擎未初始化
- 人脸位置信息错误
- 图像数据被提前释放

**解决方案**：
- 检查 `isInitialized()` 返回值
- 确保 `FaceInfo` 来自最新的 `detectFace()` 调用
- 确保图像在提取特征期间有效

### Q3: 相似度计算不准确？

**原因**：
- 特征数据无效
- 对比模式不匹配
- 阈值设置不当

**解决方案**：
- 检查 `feature.isValid()`
- 统一使用 `ASF_LIFE_PHOTO` 模式
- 根据实际场景调整阈值

### Q4: SDK 激活失败？

**原因**：
- AppID 或 SDKKey 错误
- 网络问题
- 设备时间不正确

**解决方案**：
- 核对虹软平台的应用信息
- 检查网络连接
- 校准系统时间
